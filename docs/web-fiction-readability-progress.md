# 网文可读性与首章追读优化

日期：2026-09-20

## 目标契约

- 正文先让读者看懂人物、场景和当前麻烦，再展开背景与设定。
- 每章以人物目标、阻力、选择和后果推进，减少抽象总结、说明书式设定和无功能描写。
- 首章在前 500 字内形成定位、触发事件和一次可见动作，在前 800 字内形成具体追问与即时风险。
- 章末兑现本章行动后果和下一步压力，不用无因果的黑影、来电、敲门或突然自白代替悬念。

## 本轮实现

- 新增章节 `reader_contract`：作品承诺、开场触发、立即目标、即时风险、读者追问、阶段兑现和下一步压力。
- 细纲、场景正文、整章降级、短场景续写、全文修订和质量审读统一读取该契约。
- 正文系统提示加入网文可读性规则；题材策略额外传播创作简报中的 `tone`、`style_fingerprint`、作品级 `reader_promise` 和独特锚点。
- 审读新增首章开头清晰度、即时动作、追问和风险检查；缺少证据时不凭印象报问题。
- 旧细纲通过服务端归一化补齐契约字段，保留旧 checkpoint 和既有工作流兼容性。
- 提示词契约版本更新为 `2026-09-20.1`，不改变生产开关或部署状态。
