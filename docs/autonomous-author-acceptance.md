# 自主作家模式验收与灰度说明

本轮代码是默认关闭的实验实现。以下区分可执行代码、自动化测试与尚未完成的真实验收，不能用单元测试替代作品效果。

## 入口与模块

- 创建新书提交 `author_config.author_mode=autonomous_v1`、独立契约版本、规模与 `Idempotency-Key`。
- 创作节点通过原有工作流启动/恢复、执行租约和事件持久化运行，不启用独立进程或角色 Agent。
- `application/creative/` 承担选题开发、人物决策、读者后处理、复盘、审美及反馈实验。
- `creative_sessions` 保存稳定会话、预算与恢复阶段；`creative_records` 保存不可变成果版本；`creative_requests` 逐物理请求记账；`author_records` 保存租户原创样例及档案。
- checkpoint 保留阶段、成果引用及原有工作流状态。资料正文只存数据库会话/资料成果，不随总纲再次复制。
- 控制命令与会话变更同事务保存；小说级写入使用小说行锁和既有执行租约。原有工作流契约版本不被替换。

## 六项能力矩阵

| 能力 | 代码路径 | 独立证据与失败处理 |
| --- | --- | --- |
| 选题判断 | `development.py`、`tavily.py` | 三候选、隔离试稿、正文证据盲评、独立规划评估；无市场证据记unknown；一次修复失败暂停 |
| 故事发动机 | `policy.py`、`recap.py` | 十节点契约、归档五章复盘和引用校验；合理收束不自动制造新危机 |
| 人物驱动 | `narrative.py`、`cast.py`、`lifecycle.py` | 稳定实体ID、人物职责/功能槽、最多两路线、无路径重规划一次；生死变更依赖规范事实，不以传闻确认 |
| 读者视角 | `projection.py`、`runtime.py`、`postprocess.py`、`scenes.py` | 作者/人物/读者视图分离，逐场景白名单；五类功能与1-5场景，归档后处理可恢复 |
| 作者审美 | `author_style.py`、`style_service.py`、`author_repository.py` | 原创来源、范围、版本、三组四千字限制；冲突暂停，事实/剧情修正不作为审美来源 |
| 真实反馈 | `feedback.py`、`experiments.py`、`direct_feedback.py` | 三读者两片段门槛、单因素隔离样稿、顺序交换盲评、限期试用/撤销；真人支持和模型支持分开保存 |

作者明确的人物/剧情指令在下一章边界进入已有改纲入口，仍受硬约束和窗口门禁。事实评论记录为待核实线索，提供已有事实提案/确认入口，不自动把评论写成规范事实。

## 本地检查

在 `writter_back` 使用项目环境：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

新增测试包括规则、SDK逐次请求计量、实际节点重放、部分后处理失败恢复、作者范围隔离、晋升/接力/假死、姓名池复用、DDL与ORM一致性，以及独立数据库下的预算并发和租户隔离。

在 `writter_front`：

```powershell
npm run lint
npm run test
npm run build
```

`creative-preview.html` 是开发专用隔离组件预览，显示明确的模拟数据标识，不连接数据库或模型。它用于桌面/移动端视觉检查，不是生产入口，也不是后端联调证明。

## 尚未完成的验收

1. 真实 PostgreSQL 迁移升降级、章节事务、执行租约失效及跨进程 checkpoint 恢复。独立数据库测试缺环境时跳过，不能填写通过。
2. 真实模型和 Tavily 调用的契约验收，包括在规定预算下完整完成1/4/5/6/200章任务；未静默消耗付费模型额度。
3. 新模式完整带数据库的浏览器流程。隔离组件截图仅证明相关界面可渲染和操作。
4. 长篇语义质量：人物动机合理性、核心伏笔是否真正兑现、安静章节是否有效，以及候选是否实质不同，仍须真实生成样本和人工审读。
5. 真人反馈有效性与盲评效果。手工录入的读者标识不等同于第三方身份验证，不可宣称平台留存已验证。

## 固定效果验收

固定三份都市悬疑简报，在相同模型、参数、提示词快照及规模下生成旧/新各20章；样稿命名和展示顺序隐藏模式来源并交叉平衡。

建议三类简报分别固定为：封闭社区失踪调查、城市旧案证据复核、普通职业者卷入身份谜案。正式运行前冻结详细简报、硬设定、模型配置、正文哈希和样本编号，禁止评价后调整样本。

- 5名目标读者盲评每份前3章，记录追读选择、人物记忆、跳读位置、情绪兑现与审美符合度。
- 1名编辑审读全部120章，记录人物可信度、严重事实冲突、主线因果和伏笔完成情况。
- 门槛：新版追读选择至少60%，至少2份简报优于旧版，人物可信度不下降，不新增未解决的严重事实冲突。
- 单独记录模型调用量、检索数、未知结果请求、总耗时和暂停次数；模型评分不能填入真人评价栏。
- 这是小样本工程验收，不能推导为平台销量或留存结论。

## 发布与回滚

1. 先在隔离测试库执行 `0009_autonomous_author`，再部署兼容后端、前端。生产部署需另行确认。
2. `AUTONOMOUS_AUTHOR_ENABLED`、租户 `autonomous_author_enabled` 和原有整书规划开关必须同时开启。默认关闭。
3. 优先测试租户，先小规模再长篇；旧书不补建会话、不迁移进入新模式。
4. 关闭功能时正在运行的新模式在节点/请求边界安全暂停，保留正文、成果和消耗，不静默退回旧流程。
5. 首选开关回滚。迁移 downgrade 会删除创作成果表，不应当作保留成果的生产回滚方案，执行前必须备份并另行确认。
6. 首期不接平台账号、不自动发布、不自动重写归档正文。人工编辑会使旧版本反馈失效，保留旧反馈归属而不计入新实验。
