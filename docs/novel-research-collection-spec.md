# 受限小说题材研究采集规范

版本：`novel-research-v1`  
日期：2026-09-20

## 目标

从公开目录资料中提炼题材机制、读者承诺和开局结构，服务原创创作策略；不建立整本小说正文语料库，不生成某本小说的改写稿。

## 首轮范围

- 来源分类：玄幻、武侠、恐怖、军事、女频、游戏、科幻。
- 每类10本：热门4本、新书3本、近期更新3本；重复作品按规范 URL 去重。
- 每本读取详情元数据、目录标题和首章结构。
- 首章正文只有在获得明确授权并使用本地或已授权模型时才临时读取；默认关闭。

## 来源边界

允许的页面类型只有首页、`/lists/` 分类页、`/novel/` 详情页和 `/book/` 章节页。禁止任意 URL、登录页、验证码、付费/锁定内容、代理轮换和反爬绕过。

单主机并发为1，请求间隔至少1秒，每批最多200次请求；403、429和跨域重定向立即停止该来源。原始 HTML 和正文只在内存中短暂存在，日志、数据库和模型调用账本不得写入正文。

## 结构化结果

每个采样样本生成结构化 `NovelPatternCard`，只包含：

- 来源分类与项目题材映射；
- 看点机制、读者承诺和剧情发动机；
- 受控开局标签：危机、谜团、身份反转、任务/系统、重生/穿越、关系冲突、日常转突发、世界观展示；
- `初始状态 → 异常/压力 → 第一个选择 → 阅读承诺` 的开局节拍；
- 章节号、段落位置和中文转述形式的证据；
- 置信度、限制和原创转化方向。

禁止输出原句、对白、人物专名、独特设定组合或连续剧情复述。研究结果标记为 `market_observation`，不进入事实库，不作为用户小说的规范人物或世界观事实。

## 按项目题材累积

样本只作为事实来源和去重单位，主知识对象是按 `project_genre` 生成的 `GenreKnowledgePackage`。

- 玄幻、科幻、悬疑、女频等项目题材分别维护自己的知识包。
- 一条样本只计入一个主项目题材，其他命中题材作为副标签。
- 知识包内部保留多个开局分支和看点机制，不把不同作品压成一条平均写法。
- 每次批次生成新的知识包草稿，审核通过后更新当前版本指针。
- 知识包保留样本数量、来源分类、批次和样本 ID，支持重建与回滚。
- 写作端默认只检索当前已审核知识包，单本样本仅用于审计和证据追溯。

报告不得把样本频次表述为市场因果或作品质量证明。

## 检索

v1 使用结构化关键词、题材过滤和 `pg_trgm` 预留索引，不启用向量或 embedding。检索接口固定返回题材知识包，未来可在同一知识版本 ID 上新增独立向量索引。

## 验收

- 分类配额、唯一来源 URL 和抽样层次可复核；
- 解析失败时返回未知或不完整，不用默认值伪造结论；
- 正文不落库、不进日志，未授权首章调用被拒绝；
- 输出只含结构化机制，不含可连续复制的原文；
- 旧创作工作流不读取原始研究正文。
