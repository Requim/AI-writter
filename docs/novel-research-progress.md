# 受限小说研究采集实施进度

更新时间：2026-09-20

## 当前目标

建立独立的小说研究采集服务和按项目题材累积的关键词研究库。单本小说只作为样本和证据来源，不作为主要 RAG 检索对象。

- [x] 独立 `research_service` 服务目录、配置、容器入口和 API/Worker 边界。
- [x] 受限笔趣阁 URL、请求预算、限流停止、目录/详情/首章解析逻辑独立复制到研究服务。

## 交付边界

- 研究库与写作库使用不同数据库，不共享租户表，也不修改 `novel_memories`。
- 首章正文只有在批次授权和服务配置同时打开时临时读取，分析结束后清空。
- 详情页简介只在模型处理期间驻留；落库卡片不保留原始简介。
- 未审核的类型知识只能在研究服务内部查看，不进入写作端默认检索结果。
