# 作家工作台风格统一

日期：2026-09-09

## 范围与方向

- 根据用户要求，参考番茄作家专区的公开视觉方向；未登录第三方账号，不声称逐页复刻其登录后的工作台。
- 保留墨间品牌、Ant Design、React Router、正文编辑和创作审核流程。
- 统一为浅灰页面、白色工作区、橙红操作色、细分隔线与紧凑无衬线标题。正文和书稿封面保留阅读字体。
- 不增加虚构的收益、粉丝、留存或平台发布功能。
- 本轮仅修改前端与验证文档；保留之前自主作家模式和其他未提交改动。

## 已完成

- 正式应用与开发预览共用 `src/theme.ts`，消除预览默认蓝色和旧版米色酒红风格混用。
- 作品管理、创建作品、编辑部设置共用工作区侧栏；编辑器保留完整横向空间。
- 原有路由、角色权限、租户切换、退出及未保存内容保护不变。
- 统一作品列表、创建表单、书稿预览、章节目录、正文工具栏、规划/审核区域、登录/注册及设置页的基础样式。
- 自主作家工作台改为宽抽屉、无卡片嵌套的预算统计、图标标签和成果分类列表。
- 小屏成果表保留名称和状态，类别、版本、来源可展开查看，不用横向拖动整张表。
- 移除页面入场位移动画，解决其改变 fixed 包含块、导致移动端创建底栏落在页面末尾的问题。
- 开发预览可浏览真实页面组件；模拟 API 仅操作内存，未提供的写入和模型请求被拒绝。预览不会覆盖本机真实登录信息。
