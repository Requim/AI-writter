# 自主作家模式实施进度

更新时间：2026-09-09

## 目标与边界

- 实现用户确认的六项能力：选题判断、故事发动机、人物驱动、读者视角、作者审美、真实反馈。
- 保留稳定主角/群像接力、人物生命周期、秘密及伏笔的完整证据链。
- 复用现有工作流、数据库、事实门禁、租约和事件协议；新模式默认关闭，首期只允许新书。
- 不部署生产、不发布平台、不自动运行收费模型实验；真人盲评及实际效果不可由单元测试替代。
- 用户已有未提交的题材策略、提示词快照及前端审核改动全部保留。

## 固定决策

- 新模式 `autonomous_v1`，创作契约版本独立于旧工作流版本。
- 三个选题、十个冲突节点、两个隔离单章试稿；正式首章重新生成。
- 准备阶段60次、正式章节32次/章、复盘池20+8N次；全书检索12次，立项最多6次。
- 每五章最多一次剧情路线比较、结构性改纲和可选反馈实验；最多两次改结局，最后五章冻结。
- 不改用户硬设定、归档正文、约定规模及锁定窗口。
- 真人读者、作者指令和模型评审分别记录；模型试用不得标为真人验证。
- 新角色与伏笔必须区分计划状态和正文已发生状态，读者视图不得泄露作者秘密。
